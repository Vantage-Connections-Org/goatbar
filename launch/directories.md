## hesreallyhim/awesome-claude-code (54k stars)

Rules: no formal process; recommendations via issues are reviewed best-effort. The maintainer says plainly
to get users first and submit later ("if getting on the list is part of a promotional strategy, have a backup plan").
So: wait until GoatBar has real users/stars, then open one issue:

> **GoatBar** (https://github.com/Vantage-Connections-Org/goatbar): a free, MIT Windows taskbar app that shows each running Claude Code session as a square whose background is its status (working, done, needs an answer, idle) and whose border is the session's `/color`. Reads `~/.claude/sessions` and transcripts locally; no network. Optional hook adds the current step.
